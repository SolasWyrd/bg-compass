# BG Compass

## Platform
adaptive

## Users
One person: the author, playing Hearthstone Battlegrounds on Windows. Reads the overlay in glances, mid-match, under a turn timer, with the game behind it.

## Product Purpose
Answer "what now?" in the current phase of a Battlegrounds game from the game's own log: which hero, what the board lacks, who is next and how the fight looks.

## Positioning
A private tool, free and local. Not a product to sell or explain.

## Operating Context
Dark transparent panels over a bright, busy game at any resolution. Never steals focus, never blocks clicks. One compact panel changes with the phase; marks on the game table point at the cards, heroes and seats themselves; anything else opens on demand.

## Capabilities and Constraints
- Log file and card data only. No memory reading, code injection or input simulation.
- Personal stats only; no global win rates. Lobby tribes are unknown until seen. No MMR.
- Simulator is a beta with known gaps.
- Network: card data, card art, GitHub Releases for updates. No personal data sent.

## Brand Commitments
None.

## Evidence on Hand
Owner verdict on the previous UI: looked like 1990s-2000s software, far too much text.

## Product Principles
- Numbers and short labels first; reasons and limits on hover.
- A guess never looks like a measurement: a compact mark is enough, a sentence is not needed.
- If there is nothing to say, show nothing.
