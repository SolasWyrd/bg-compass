# BG Compass

Панель и метки прямо на игровом поле Hearthstone Battlegrounds для Windows 10/11 x64: герои, билд, соперники, шансы в бою, статистика. Работает по `Power.log`. Память игры не читает, код не внедряет, ввод не имитирует.

## Запуск

1. Скачайте `BgCompass-win-x64.zip` из [Releases](https://github.com/SolasWyrd/bg-compass/releases/latest), распакуйте, запустите `BgCompass.exe`. SmartScreen: «Подробнее» → «Выполнить в любом случае» (сборка без подписи).
2. Настройки → «Включить логи», затем перезапустите игру.
3. Играйте в окне или в окне без рамки.

| Клавиши | Действие |
|---|---|
| Ctrl+Shift+H | показать или скрыть панель |
| Ctrl+Shift+T | клики сквозь панель |

На поле: рамка «Брать» или «Тройка» вокруг карт в магазине, среднее место над героями на выборе, племя и возраст доски у таблицы лидеров, шансы боя сверху. Наведите курсор на метку, чтобы увидеть детали. Клики всегда проходят в игру. Если метки не совпали с картами: Настройки → «Показать разметку» и ползунки сдвига.

Панель двигается за заголовок. Причины и ограничения видны при наведении. Плитка с заливкой означает измеренное значение, контурная означает оценку по правилу.

## Обновление

Программа раз в 6 часов проверяет GitHub Releases, скачивает новую версию и сверяет SHA-256. Кнопка обновления появляется в заголовке панели, в настройках и в трее.

Выпустить версию: `./release.sh 0.2.0` (нужны чистое дерево, .NET 10 SDK и `gh`).

## Сеть и данные

Запросы идут только к HearthstoneJSON (карты и картинки) и GitHub Releases (обновления). Личные данные никуда не отправляются. Настройки, история и журнал лежат в `%LOCALAPPDATA%\BgCompass\`.

EULA Blizzard (раздел 1.C) запрещает программы, дающие преимущество. Разрешения для оверлеев нет, риск за вами.

## Сборка

Нужен .NET 10 SDK.

```bash
dotnet test BgCompass.sln
```

```bash
./build-win.sh
```

Режимы без игры: `--replay <Power.log> [--speed N] [--gamestate]`, `--render-ui <папка>`, `--smoke-exit <секунды>`.
